# CrossFit Box App

Dieses Repository enthält den klickbaren Mockup-Prototyp für eine CrossFit-Box-Verwaltungs-App (Mandanten-, User- und Kursverwaltung, Shop, Leaderboard, Beamer-Ansicht).

Siehe [`mockup/`](mockup/) für den Prototyp — einfach `mockup/index.html` im Browser öffnen, kein Build/Server nötig.

Das eigentliche Projekt-Setup (Architektur, Backend, Datenbank) folgt als separater Schritt nach Abstimmung der Mockups.
